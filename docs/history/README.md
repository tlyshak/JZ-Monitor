## Як вести далі

- Новий етап роботи — новий файл `YYYY-MM-DD_<тема>.md` і рядок у таблиці вище.
- Пишіть **рішення й причини** (що попросив власник, що відкинули і чому), а не переказ diff: код і `git log`
  це вже зберігають.
- Факти про протокол і авто — у [`docs/PROTOCOL.md`](../PROTOCOL.md); тут лише посилання на них.
- Правила проєкту — у [`CLAUDE.md`](../../CLAUDE.md). Якщо історія суперечить CLAUDE.md, правильний CLAUDE.md.
